# IMAGO — Design Principles (standing brief, provided by user 2026-09-23)
Apply to every page/component built for this project:

- Modern premium UI, not generic AI-generated layouts
- Strong visual hierarchy
- Generous whitespace
- Consistent 8px spacing system
- Max content width around 1200–1400px
- Clear CTA hierarchy
- Mobile-first responsive design
- WCAG-friendly contrast
- Subtle animations and micro-interactions
- Avoid excessive gradients, glassmorphism and random cards
- Avoid making every section look identical
- Use strong editorial typography
- Create reusable components
- Think about UX flow before visual styling
